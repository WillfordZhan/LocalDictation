# Windows 预览版实施与验收

## 本次目标

发布 Mac 0.5.8 修复版，并提供 Windows 10/11 x64 的可分发预览版。Windows 先支持普通 CPU 电脑；无需 NVIDIA 显卡、系统 Python 或系统 .NET。模型首次下载，历史和模型保存在用户应用数据目录，与程序分离。

## 实现边界

- WPF 原生界面和托盘：全局组合快捷键、录音浮窗、连续多段、顺序填入、历史分页、手动词典、Prompt 版本和配置检查。
- 本机 Python 服务复用现有 HTTP、流式调度和正文校验。Whisper large-v3 turbo 通过 CTranslate2 int8 识别；Qwen3-4B-Instruct-2507 Q4_K_M 通过独立 llama.cpp 进程润色。
- 模型文件固定版本及 SHA-256；下载可续传，校验完成才标记就绪。此包不携带模型或用户数据。
- 前台输入框与光标变化、密码框、剪贴板被占用、权限不足时不盲目重试粘贴。用户仍可从历史取回结果。
- Windows 首版暂不宣称与 Mac 功能完全一致；自动纠错学习、热力图和 GPU 加速不在本次已实现范围。

## 验收顺序

1. 协议与存储测试：正文 JSON、异常原文回退、分段调度、固定模型下载和损坏文件恢复。
2. GitHub 托管 Windows 环境编译、自检与界面截图；使用独立测试目录，不连接内网电脑。
3. 自带运行环境从独立目录启动；不借用构建机的 Python、.NET 或 site-packages。
4. 真实生产模型处理公开的合成中文/中英混合录音，记录 ASR 和润色耗时；不以 mock 或 tiny 模型替代这一项。
5. 在专用测试文本框验证全局快捷键、HUD 不抢焦点、一次自动粘贴、焦点/选区变化和剪贴板回退。
6. 检查 ZIP、依赖许可证、模型和隐私文件排除；提交代码、运行 CI 后发布 Windows 预览资产。

自动桌面测试不能替代真实使用者的麦克风与第三方编辑器验收。最终说明应分别列明已验证入口和仍需验收的边界，不把编译通过称为端到端通过。
