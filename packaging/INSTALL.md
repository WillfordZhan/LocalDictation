# 本地口述 · Apple Silicon 内测包

将 ZIP 解压，把 LocalDictation.app 移入“应用程序”后打开。在“模型与配置”中点“一键配置”，首次联网下载识别与文字润色模型，完成后即可离线使用。应用内置运行环境，无需安装 Python、Homebrew 或命令行工具。

默认模型为 **Qwen3-ASR-1.7B-8bit + Qwen3.5-4B-4bit**，模型下载总量约 **5.53 GB**；选择 **Qwen3.5-9B-4bit** 润色时，与默认 ASR 组成的整套模型约 **8.44 GB**。体积按发行模型清单的文件字节数计算（1 GB = 10 亿字节），不含应用和已保留的其他模型。若已有默认组合，再添加 9B 仅需下载 9B 模型，约 5.98 GB。

首页可直接切换 Qwen3 ASR / Whisper，以及 Qwen3.5 4B / 9B。未下载的模型首次使用时需要联网下载和校验；已验证的文件会复用，下载失败或取消后可重试。切换需等待当前口述与整理完成，加载完成后各模型分别显示“已就绪”。当前使用官方 Hugging Face 下载源，未验证所有地区的网络可达性。

升级后，原默认润色配置改为使用 Qwen3.5 4B；已经选择 Qwen3.5 9B 的用户继续保留 9B。旧模型文件不会自动删除。

在应用中分别允许麦克风、自动填入以及需要时的 Fn 输入监控。macOS 的系统授权需要本人点击，应用不会自动授权。可以先使用普通组合快捷键；无法自动填入时，结果会复制到剪贴板并提示按 ⌘V 粘贴。

历史原文与整理结果、Prompt 版本、个人词典、统计和模型保存在 `~/Library/Application Support/LocalDictation/`。更新或删除应用不会主动删除这里的数据。不要删除这个数据文件夹，也不要用旧备份覆盖新记录。

## 保留一个安装入口

安装后只保留一个固定位置的 `LocalDictation.app`，Dock 固定此路径。升级时先结束口述、等待整理完成，再退出应用并在同一路径替换；不要把新版本固定为另一个 Dock 项。

开发和验收的临时应用放在隐藏目录或 `.noindex` 目录，更新验证完成后清理。备份使用 Git 版本、ZIP 归档或独立数据文件，不把可启动的 `.app` 留在工作目录与升级备份中，以免系统把它们列成多个同名应用。

如果更新时移动过旧应用，Dock 的文件书签可能仍需刷新。检查固定项的 URL 与书签均指向保留的安装路径，重新固定这一项并保留原顺序；只注销本应用旧路径的 LaunchServices 记录，无需重建其他应用的注册信息。这是安装维护步骤，不代表应用会自动下载新版本。

开发者在完成原路径替换后，可使用下面的工具刷新已固定的入口。它仅匹配本应用的一个现有 Dock 项，刷新书签、图标缓存标识和文件日期，保留顺序和其他项目，先备份配置，再校验写入结果；没有固定项或出现多个匹配时会停止。备份位于应用外的 `UpgradeBackups/Dock`，不会进入源码仓库。

```sh
swift packaging/refresh_macos_dock.swift --dry-run /absolute/path/LocalDictation.app
swift packaging/refresh_macos_dock.swift /absolute/path/LocalDictation.app
```

工具不会重启 Dock；如图标仍被缓存，可在更新完成后重新启动 Dock。

本包面向 Apple Silicon，声明最低 macOS 14；完整运行验证在开发者当前 Mac 上完成，尚未完成其他硬件和最低系统版本的验收。当前使用本机稳定自签名证书，**未使用 Apple Developer ID 签名，也未经过 Apple 公证**。在其他 Mac 上首次打开可能受到系统拦截；若系统提示无法打开，请在“系统设置 → 隐私与安全性”中核对来源后选择“仍要打开”。跨设备及带下载隔离标记的首次打开仍待验证。

运行环境内保留 CPython 及依赖包的许可文件；模型来源和许可信息见应用附带的 THIRD_PARTY_NOTICES.md。默认识别与润色均在本机运行，不发送转写文本到云端；云端整理只有在用户另外配置并开启时才发送转写文本。
