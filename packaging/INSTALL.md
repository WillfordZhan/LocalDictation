# 本地口述 · Apple Silicon 内测包

将 ZIP 解压，把 LocalDictation.app 移入“应用程序”后打开。在“模型与配置”中点“一键配置”，首次联网下载识别与文字整理模型，完成后即可离线使用。无需安装 Python、Homebrew 或命令行工具。

默认模型为 Qwen3-ASR-1.7B-8bit 和 Qwen3-4B-Instruct-2507-4bit，总下载约 4.75 GB；应用已内置约 1.26 GB 的运行环境。下载失败或取消后可重试，已验证的文件会复用。旧用户保留已有的模型选择。当前使用官方 Hugging Face 下载源，未验证所有地区的网络可达性。

在应用中分别允许麦克风、自动填入以及需要时的 Fn 输入监控。macOS 的系统授权需要本人点击，应用不会自动授权。可以先使用普通组合快捷键；无法自动填入时，结果会复制到剪贴板并提示按 ⌘V 粘贴。

历史原文与整理结果、Prompt 版本、个人词典、统计和模型保存在 `~/Library/Application Support/LocalDictation/`。更新或删除应用不会主动删除这里的数据。不要删除这个数据文件夹，也不要用旧备份覆盖新记录。

本包面向 Apple Silicon，声明最低 macOS 14；完整运行验证在开发者当前 Mac 上完成，尚未完成其他硬件和最低系统版本的验收。当前是本机稳定证书签名的内测包，**尚未通过 Apple Developer ID 公证**。正式公开下载发行还需发行者完成 Developer ID 签名、公证和带下载隔离标记的首次打开验证；本包不保证在其他 Mac 上无系统拦截地打开。

运行环境内保留 CPython 及依赖包的许可文件；模型来源和许可信息见下载目录中的 README.md。录音识别默认在本机运行，云端整理只有在用户另外配置并开启时才发送转写文本。
